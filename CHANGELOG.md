## 2.0.0 (2026-11-01)

### ⚠ BREAKING CHANGES

* ezbot.ai has been shut down. Every public SDK method is now a guarded no-op that logs a console message. `initEzbot` / `initEzbotWithServerSidePredictions` resolve with an inert tracker stand-in, and `window.ezbot` is no longer populated. This repository is archived and the package is deprecated.
